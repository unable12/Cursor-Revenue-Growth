# Cursor Revenue Growth Timeline

## From Founding to $300M ARR in Just Over 3 Years

## 📊 Overview

An interactive visualization of Cursor's incredible revenue growth journey, from its founding in January 2022 to reaching $300M ARR by April 2025. Built with React and Recharts, this project showcases the remarkable trajectory of one of the most promising AI-powered code editors.

## ✨ Features

- Interactive timeline visualization
- Smooth animations and transitions
- Responsive design
- Key milestone indicators
- Clean and modern UI

## 🛠️ Technologies Used

- React
- Recharts
- TailwindCSS
- Vite

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/unable12/Cursor-Revenue-Growth.git
```

2. Install dependencies:
```bash
cd Cursor-Revenue-Growth
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`
